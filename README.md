# DishPatch - Éttermi rendszer 

Ez a projekt egy 3. féléves egyetemi rendszerfejlesztési feladat keretében készült féléves beadandó. 

A DishPatch egy éttermi rendelés- és készletnyilvántartó szoftver prototípusa (skeletonja). A célunk egy olyan alkalmazás tervezése és alapjainak leprogramozása volt, ami megkönnyíti a pincérek, a konyha és a diszpécserek közötti kommunikációt, kiváltva a papíralapú blokkokat.

## Dokumentáció

A projekt teljes szoftvertervezési dokumentációja (Vízió, SRS, Analízis, Rendszerterv, Tesztelés) HTML formátumban megtalálható a repository `/docs` mappájában. Az olvasáshoz csak nyisd meg az `index.html` fájlt a böngésződben.
